OpenHarmony 架构总览

应用层

系统应用、第三方应用

框架层

ArkUI、应用框架、DFX

系统服务层

分布式软总线、安全、多媒体

内核层

LiteOS、Linux、驱动子系统

基础系统类型

轻量系统

面向MCU类处理器（如 Arm Cortex-M）

  • 最小内存: 128KiB
  • LiteOS-M 内核
  • 适用于穿戴设备、传感器

小型系统

面向应用处理器（如 Arm Cortex-A）

  • 最小内存: 1MiB
  • LiteOS-A / Linux 内核
  • 多媒体、图形框架

标准系统

面向高性能应用处理器

  • 最小内存: 128MiB
  • Linux 内核
  • 完整应用框架、3D GPU

内核与驱动子系统

多内核架构

  • 支持 LiteOS-M（轻量系统）和 LiteOS-A/Linux（小型/标准系统）
  • 通过 KAL（内核抽象层）提供统一接口
  • 适配不同资源等级设备

统一驱动框架 (HDF)

  • 弹性化框架，支持百K到百兆设备
  • 规范化接口，一次开发多系统部署
  • 组件化模型，降低开发与维护成本
