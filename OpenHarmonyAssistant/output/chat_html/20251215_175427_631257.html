OpenHarmony 多内核设计

面向不同资源级别的设备，OpenHarmony 采用多内核架构，灵活适配从轻量级 IoT 设备到高性能智能终端的多样化需求。

内核类型详解

L

LiteOS-M

专为资源极度受限的MCU设计，适用于百K级内存设备。

  • 轻量级任务管理、内存管理
  • 支持MPU隔离
  • 硬件高度解耦
L

LiteOS-A

面向小型系统，支持M级内存，具备更丰富的内核机制。

  • 虚拟内存、多进程支持
  • 统一驱动框架HDF
  • 1200+ POSIX接口
L

Linux

基于LTS内核演进，适用于高性能标准系统。

  • 支持4.19.y / 5.10.y / 6.6.y LTS
  • 完整应用框架与3D GPU支持
  • GPL-2.0协议合规
