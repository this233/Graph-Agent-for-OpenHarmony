项目概览

核心目标

面向全场景、全连接、全智能时代，基于开源方式，搭建智能终端设备操作系统的框架和平台，促进万物互联产业的繁荣发展。

设计理念

采用组件化设计，支持在128KiB到xGiB RAM资源的设备上运行系统组件，按需弹性部署，覆盖多种CPU架构。

技术架构

内核层

  • 多内核设计 (Linux/LiteOS)
  • 内核抽象层 (KAL)
  • 驱动框架 (HDF)

系统服务层

  • 分布式软总线
  • 分布式数据管理
  • 分布式任务调度
  • 安全、AI、图形等子系统

框架层

  • C/C++/JS 用户程序框架
  • Ability 框架
  • ArkUI 框架 (JS)
  • 多语言 API

应用层

  • 系统应用
  • 第三方应用
  • FA (有UI) / PA (无UI)

核心特性

硬件互助，资源共享

  • 分布式软总线

    设备间无缝互联，统一通信能力。

  • 分布式数据管理

    数据与设备解绑，跨设备无缝衔接。

  • 分布式任务调度

    智能选择设备运行任务。

  • 设备虚拟化

    多设备资源融合，形成超级终端。

开发与部署

  • 一次开发，多端部署

    统一框架保证应用一致性。

  • 统一OS，弹性部署

    组件化设计，适应128KiB到GiB设备。

  • 多架构支持

    全面覆盖ARM、RISC-V、x86等。

系统类型

类型 处理器 最小内存 能力
轻量系统 (mini system) MCU类 (Cortex-M, RISC-V 32位) 128KiB 轻量级网络协议、图形框架、IoT总线部件。适用于传感器、穿戴设备。
小型系统 (small system) 1MiB 标准图形框架、多媒体能力、更高安全。适用于IP Camera、路由器。
标准系统 (standard system) 应用处理器 (Cortex-A) 128MiB 增强交互、3D GPU、完整应用框架。适用于高端显示屏。
