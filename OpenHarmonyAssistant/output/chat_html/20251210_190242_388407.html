OpenHarmony 技术架构

探索 OpenHarmony 的四层架构、系统类型与核心特性，通过交互式卡片深入了解其分布式能力。

系统类型

轻量系统 (Mini System)

  • 处理器: Arm Cortex-M, RISC-V 32
  • 最小内存: 128KiB
  • 能力: 轻量级网络、图形框架、IOT总线

小型系统 (Small System)

  • 处理器: Arm Cortex-A
  • 最小内存: 1MiB
  • 能力: 安全、图形、多媒体

标准系统 (Standard System)

  • 处理器: Arm Cortex-A
  • 最小内存: 128MiB
  • 能力: 增强交互、3D GPU、完整应用框架

四层架构

内核层

  • 内核子系统: 多内核设计 (Linux / LiteOS)
  • 驱动子系统: HDF驱动框架

系统服务层

  • 分布式软总线
  • 分布式数据管理
  • 图形、安全、AI等

框架层

  • ArkUI框架 (JS)
  • Ability框架
  • 多语言API

应用层

  • 系统应用
  • 第三方应用
  • FA/PA能力

核心特性

硬件互助

  • 分布式软总线
  • 分布式数据管理
  • 分布式任务调度
  • 设备虚拟化

一次开发

  • 用户程序框架
  • Ability框架
  • UI框架
  • 多端部署

统一OS

  • 组件化设计
  • 弹性部署
  • ARM/RISC-V/x86
  • 百KiB到GiB RAM

核心子系统

  • 驱动 (HDF)
  • 图形 (ArkUI)
  • 安全
  • AI

代码示例 (SysCap) 

// 查询设备是否支持定位能力
import geolocation from '@ohos.geolocation'

const isLocationAvailable = canIUse('SystemCapability.Location.Location');
if (isLocationAvailable) {
  geolocation.getCurrentLocation((location) => {
    console.log(location.latitude, location.longitue);
  });
} else {
  console.log('Location not supported by this device.')
}
